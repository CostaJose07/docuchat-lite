DocuChat Lite

A simple LLM-powered document Q&A application built with Python, Streamlit, and OpenAI.

Features
Natural-language questions about pasted documents
Context-grounded answers
Instructions to acknowledge missing information
Simple browser-based interface
Tech Stack
Python
Streamlit
OpenAI Responses API
Run locally

Install dependencies with pip install -r requirements.txt, then run streamlit run app.py.

Limitations

This prototype uses pasted text rather than a full document retrieval pipeline. Answers should be verified against the source text.

Future Improvements
PDF uploads
Retrieval-augmented generation (RAG)
Automated evaluation and source citations
